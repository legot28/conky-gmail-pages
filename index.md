# Conky Gmail Desktop

Conky Gmail Desktop is a personal Linux desktop utility that displays the number of unread messages in the owner's Gmail account.

## Purpose

The application is intended for personal use by its owner. It uses Google's Gmail API to retrieve unread message counts.

## Data and privacy

The application uses Google OAuth 2.0 for authorization. It retrieves unread message counts for display on the owner's desktop. It is not intended to sell or share personal information.

## Contact

For questions about this application, contact the owner through the Google account associated with its OAuth configuration.
